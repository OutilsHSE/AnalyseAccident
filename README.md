# Analyse d'accident — CDES

Page publique de l'analyse d'événement accidentel (GitHub Pages). Version V2 du 05/10/2026.

| Fichier | Rôle |
|---|---|
| `index.html` | la page (structure et images) |
| `css/aa.css` | la mise en forme |
| `js/aa.js` | l'application : recueil des faits, arbre des causes, plan d'actions, courrier, flash |
| `courrier_template.docx` | gabarit Word du courrier « culture juste » (à garder à côté de `index.html`) |
| `flash_template.pptx` | gabarit PowerPoint du flash HSE (idem) |

**Ce dépôt ne contient ni adresse de serveur, ni mot de passe, ni clé.** L'appareil est
« branché » en ouvrant l'analyse depuis la tuile de l'intranet HSE. Le bouton « Exemple »
charge un cas anonymisé.
